# Exercise Index

Work through these exercises in order — each one builds on the last.

## Tips for Learning with an AI Assistant

**Describe symptoms, not solutions.** Instead of "write me a useEffect", say:
> "My component fetches data but the page keeps reloading in a loop. Here is my code: [paste code]. What is causing this?"

**Share your error messages.** Copy the full console error and include it in your prompt.

**Ask "why", not just "fix this".** After the AI proposes a fix, ask:
> "Why does the original code fail? What concept am I missing?"

**Iterate.** If the first answer doesn't work, describe exactly what happened and ask again.
